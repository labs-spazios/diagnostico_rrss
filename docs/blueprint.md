# **App Name**: Dueño Test

## Core Features:

- Initial Data Collection: Collect user data (Name, Age, Gender) at the beginning of the test. Store all responses for later retrieval. Adapt questions and language based on gender selection to ensure correct masculine/feminine forms (e.g., dueño/dueña, contento/contenta).
- Interactive Sliders: Implement slider interactions for questions with opposing options. Ensure sliders include icons with red on the left and green on the right.
- Multiple Attempt Tracking: Allow users to add multiple 'attempt' entries with descriptions. Implement a dynamic counter for attempt numbers.
- Barrier Selection: Display multiple choice options as checkboxes in two columns. Randomize the order of options, excluding 'Ninguna' and 'Otra'.
- Dynamic Content Display: Conditionally display input fields based on the 'Alquilar' radio button selection and perform rental calculation.

## Style Guidelines:

- Primary color: #B81826
- Additional colors will be in grayscale.
- Header will contain the image previously provided.
- Progress bar at the top indicating user's progress through the test.
- Slide number label at the bottom for easy reference.
- Include related icons to each slider and question.
